# tasks/ — what's undone and how to pick up

Planning, not documentation. `docs/` explains the system; this folder tracks work on it.

## What lives here

- **`backlog.md`**: open work only, tiered MVP / Core / Later. No Done section.
- **`handoff.md`**: standing orientation for a fresh session. Rewritten in place.

## Naming

Fixed names, no date prefixes.

## Read first if

You're starting a session (backlog `## MVP` only), or deciding what to build next.

## Skip / don't read

`## Later` in the backlog unless you're planning. Grep it on demand.

## Discipline

- Completed items are **deleted**, not ticked. The record is `NOTES.md` + git.
- Every item has trigger, pointer and ripple.

## Cross-references

- **Consumes:** `docs/DESIGN.md` (roadmap source), `NOTES.md` (test logs produce bugs).
- **Feeds:** `STATE.md` § What's next.
